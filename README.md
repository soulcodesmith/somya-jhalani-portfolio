## 🌟 Overview & Design Philosophy

This repository contains the complete single-page personal portfolio and digital literacy capstone for **Somya Jhalani**. Designed with an editorial, minimalist aesthetic inspired by **Linear, Apple, and Vercel**, this website bridges foundational computer science principles, practical digital literacy, and modern web engineering.

### 🎨 Design System
- **Theme:** Sophisticated dark mode (`#09090b` canvas with subtle hairline borders `border-white/10`).
- **Typography:** Inter (editorial body and bold headings) paired with Geist Mono / JetBrains Mono for code elements.
- **Glassmorphism:** `backdrop-blur-xl bg-white/[0.02]` with smooth 200ms scale/lift micro-interactions and ambient radial gradients.
- **Visuals:** Modern Lucide icons, accessible ARIA labels, and responsive layout scaling from 320px mobile screens to 4K displays.

## 🚀 Quick Start / Local Preview

Because this project is built with clean semantic HTML5, modern Tailwind CSS (via CDN), and vanilla JavaScript, **no build step is required**.

You can run it in any of the following ways:

### Option 1: Double-click to Open
Double-click `index.html` in your file explorer to open it in any modern browser.

### Option 2: Local HTTP Server
```bash
# Using Python 3
python3 -m http.server 3000

# Open in browser: http://localhost:3000
```
